# Configuración

Este módulo reúne los ajustes básicos de tu hotel. Conviene completarlo **antes** de empezar a registrar reservas y ventas.

![Menú Configuración de TAQINIHOTEL](/img/configuracion-menu.png)

::: tip Orden recomendado
Sigue este orden para no quedarte sin datos en pantallas posteriores:
1. Datos de empresa
2. Sedes, áreas y pisos
3. Tipos de habitación y tarifas
4. Servicios y categorías
5. Cajas y su asignación
:::

## Opciones del módulo

| Opción | Para qué sirve |
|--------|----------------|
| [Datos de empresa](./datos-empresa) | Razón social, RUC, dirección y logo |
| [Área del hotel](./area-hotel) | Zonas del hotel |
| [Sedes](./sedes) | Gestión de Sedes |
| [Tipos de habitación](./tipos-habitacion) | Simple, doble, matrimonial, suite, etc. |
| [Tarifas](./tarifas) | Descuento en porcentaje al total de la reserva  |
| [Pisos](./pisos) | Pisos y sus habitaciones |
| [Servicios](./servicios) | Servicios adicionales que ofreces |
| [Categoría de servicios](./categoria-servicios) | Agrupación de servicios |
| [Áreas de ventas](./areas-ventas) | Áreas donde se venden los servicios adicionales |
| [Numeración de documentos](./numeracion-documentos) | Series y correlativos |
| [Gastos y créditos](./gastos-creditos) | Registro de gastos y créditos  |
| [Cajas](./cajas) | Cajas del hotel |
| [Asignación de cajas](./asignacion-cajas) | Qué caja se asigna a cada Sede |
| [Tipo de metas](./tipo-metas) | Tipos de metas |
| [Metas](./metas) | Metas de venta |
