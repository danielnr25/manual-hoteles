# Introducción

Bienvenido al manual de usuario de **TAQINIHOTEL**, el sistema de gestión hotelera de Taqini.

Aquí aprenderás a administrar reservas, habitaciones, huéspedes y reportes de tu hotel, paso a paso.

![Panel principal de TAQINIHOTEL](/img/panel-hotel.png)

::: info A quién va dirigido
Este manual es para administradores y recepcionistas del hotel. No necesitas conocimientos técnicos.
:::

## Antes de empezar

Necesitarás:

- Un dispositivo con conexión a internet (computadora, tablet o celular).
- Un navegador actualizado, como Chrome, Brave o Safari.
- Un grupo de WhatsApp con el equipo de soporte de Taqini.

## Datos de acceso

Al contratar el servicio, el equipo de soporte te enviará por el grupo de WhatsApp:

| Dato | Ejemplo |
|------|---------|

::: danger Cambia tu contraseña
Por seguridad, cambia la contraseña temporal en tu primer ingreso. No la compartas con nadie.
:::

::: warning Importante
Este manual está en constante actualización. Si algo no coincide con lo que ves en pantalla, escribe al soporte.
:::
